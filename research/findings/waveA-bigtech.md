## Key finding
At least five orgs (Zalando, Vercel, Intercom, Rewind, Adyen) have published **three-tier PR risk classification** in 2026. In the stronger designs, the final verdict comes from deterministic code plus path rules. LLM output feeds into the verdict but cannot override the path rules. This is direct prior art and validation for LIGHT/STANDARD/DEEP. Our differentiator has to be the **decision extraction and named sign-off**, not the triage itself.

## What Decision-First Review should take
1. **Deterministic verdict engine.** Model output is evidence only. Tier comes from unit-tested code (Rewind, Vercel). Ship a test suite for the triage rules.
2. **Policy file of always-DEEP paths.** CODEOWNERS-protected. Includes authn/z, secrets, crypto, payments, and "changes to who can approve" (Rewind). The LLM can never downgrade it.
3. **Risk from content, not size.** Plus a separate size cap that forces DEEP or a split (Rewind, Intercom, Vercel 100+ files).
4. **Tier rules traceable to past incidents.** Each rule carries an incident ID (Zalando, DoorDash profiles). This gives bank auditors a reason for every rule.
5. **Adyen's risk dimensions as decision prompts.** Behaviour change, reversibility, rollout safety, security, and an explicit **UNKNOWN** tier that defaults to a human.
6. **Diff-matches-intent check** as a first-class evidence item (Intercom).
7. **Verification ladder before any human sees a change.** Build → tests → re-run the static analyzer that motivated the change (FixrLeak). Fast type checks such as NullAway run on every build.
8. **Disprove-it pass plus file:line evidence requirement.** Drop findings CI already catches (DoorDash).
9. **Route the sign-off to the named owner of the touched concept**, e.g. the flag author or path owner (Piranha). Non-human authors always need a human merge (Rewind, Monzo).
10. **Go-live discipline.** Shadow mode, then an agreement-rate gate (90%), then labelled and queryable verdicts, a `/request-human` override, suppressions that expire, and a benchmark that includes benign PRs to test restraint (Rewind, DoorDash).
